# Risk Register

| Risk | Impact | Mitigation |
|---|---|---|
| Very small dataset | Model performance may not generalize | Collect more data |
| Dataset may not represent all customers | Biased predictions | Check representation |
| False positive | Unnecessary retention outreach | Human review |
| False negative | Missed retention opportunity | Monitor recall |
| Data leakage | Unrealistically high evaluation | Verify feature timing |
| Privacy exposure | Customer information could be misused | Minimize and protect data |
| Automated decisions | Customers may be unfairly affected | Keep humans in the loop |
| Model drift | Performance may decline over time | Continuous monitoring |
| Poor data quality | Incorrect predictions | Regular data validation |
| Over-reliance on model | Business team may treat prediction as fact | Document limitations |
